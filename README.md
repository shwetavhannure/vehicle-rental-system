# LetzGo - Vehicle Rental Android Application

An interactive, user-friendly Android application designed to facilitate seamless two-wheeler rentals (bikes and scooters) across popular cities. The app allows users to search available vehicles by date and location, explore categorized fleets, view pricing details, manage bookings, and maintain user profiles.

---

## 🚀 Project Overview

The **LetzGo** Android app provides an end-to-end self-drive vehicle rental service platform. It addresses urban mobility needs by connecting users with available two-wheelers, including motorcycles and scooters. Built with a modern dark theme and intuitive navigation, the app delivers a quick and smooth rental experience from user registration to booking management.

---

## 🎯 Objectives

* Provide an easy-to-navigate interface for renting bikes and scooters.
* Enable location-based vehicle exploration across multiple popular cities (e.g., Kolhapur, Sangli, Satara, Solapur, Nashik, Nagpur).
* Allow flexible date-range selection for scheduling pickup and drop-off times.
* Offer category filtering (All, Bikes, Scooters) for quick vehicle selection.
* Maintain user booking history with options to view location details or cancel bookings.
* Ensure secure local authentication and profile management.

---

## 🛠️ Tools & Technologies

* **Language:** Java
* **User Interface:** XML (Material Design Components, Dark Theme UI)
* **Database:** SQLite (Local Database Helper for users, vehicles, and bookings)
* **IDE:** Android Studio / VS Code
* **Build System:** Gradle (Kotlin DSL)

---

## 📌 App Features

✔️ **Splash Screen & Branding:** Custom animated entry featuring the LetzGo logo.  
✔️ **User Authentication:** Secure Sign Up and Login interface using mobile credentials and personal info.  
✔️ **City Selection:** Grid-based selection of popular cities (Kolhapur, Sangli, Satara, etc.).  
✔️ **Date-Based Search:** Interactive date pickers for setting rental start and end dates.  
✔️ **Renting Fleet Categorization:** Filter vehicles by categories (All, Bikes, Scooters) with daily pricing and kilometer limits.  
✔️ **Booking Management:** Dedicated booking history view showing active/past bookings, total fare, location details, and cancellation options.  
✔️ **User Profile:** Personal account dashboard displaying name, mobile number, email, and a secure logout button.  
✔️ **Bottom Navigation Bar:** Smooth switching between Rent, Bookings, and Profile tabs.  

---

## 💡 Key Highlights

* **Zero Deposit Options:** Clear transparent pricing starting from competitive daily rates with zero deposit badges.
* **Safe & Sanitized Assurance:** Promotes vehicle hygiene and customer safety.
* **Offline First Architecture:** Powered by local SQLite storage for seamless responsiveness.
